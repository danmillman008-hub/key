# بستهٔ ایجنت برنامه‌ریزی مبتنی بر شواهد ماز

نسخهٔ پژوهشی اجرایی ۰٫۳ — ۱۸ اکتبر ۲۰۲۶

**این بسته الگوریتم داخلی یا رسمیِ منتشرنشدهٔ ماز نیست.** قواعد صریح دفترچه‌های ماز را از سیاست‌های مهندسی پیشنهادی جدا می‌کند. برای حالت‌هایی که سند مستقیم نداریم، نام «ماز» روی ضرایب ابداعی نمی‌گذارد. رشتهٔ بررسی‌شده تجربی است؛ تعمیم خودکار به ریاضی/انسانی ممنوع.

## پاسخ مستقیم به «فرمول خودِ ماز چیست؟»

**[فرمول ماز از روی جدول پُرشده](docs/MAZ_FORMULA.md)** سند اصلیِ کشف ساختار است: جدید/مروری، توالی لقمه‌ها، نقش روزها، حسابِ ۶۴زنگِ نمونه و مقایسهٔ مستقل با برنامهٔ رتبه‌لند. دادهٔ دستیِ کنترل‌شده در `data/verified_12T_case.json` است.

تفکیک دامنه: `planner/workload.py` و `docs/FORMULAS.md` ابزار و صورت‌بندیِ پیشنهادیِ قبلی‌اند؛ **فرمول کشف‌شدهٔ ماز محسوب نمی‌شوند**. فرمول رتبه‌لند در این بازبینی بازطراحی نشده؛ فقط طرف مقایسه است.

## برای استفاده فقط این دستور را بدهید

> `AGENT_PLAYBOOK.md` را اجرا کن. وضعیت دانش‌آموز: … . آزمون هدف و بودجه: … . خروجی را در قالب باکس‌های راهنمای قبلی بساز؛ قواعد محتوایی را از این بسته بگیر. مجهولات مؤثر را بپرس؛ برنامهٔ غیرممکن یا دادهٔ جعلی نساز.

**اصلاح مهم:** [بازمهندسی جدول‌های پُرشده و حسابرسی فرمول اولیه](docs/REVERSE_ENGINEERING.md) شامل قواعد جدیدِ رنگ/کلاس، طول متغیر زنگ، نسبت۲به۳ و محاسبهٔ۴۷ساعت/۴۹۵تست است.

## مسیر خواندن

1. [راهنمای ایجنت](AGENT_PLAYBOOK.md): ورودی تا تحویل، نحوهٔ پرکردن باکس‌ها.
2. [فرمول‌ها](docs/FORMULAS.md): زمان، لقمه، تست، اولویت و بازبرنامه‌ریزی.
3. [حالت‌های خاص](docs/SCENARIOS.md): پایه، مدرسه، پشت‌کنکور، عقب‌ماندگی، کلاس، خواب، امتحانات.
4. [دفتر شواهد](docs/EVIDENCE.md): صفحه و منبعِ هر قاعده، تعارض‌ها و میزان اطمینان.
5. [وضعیت پژوهش و کمبودها](docs/RESEARCH_STATUS.md).
6. [قرارداد خروجی و کنترل کیفیت](docs/OUTPUT_QA.md).
7. [اتصال دقیق به قالب Word قبلی و رفع ثابت‌های قدیمی renderer](docs/TEMPLATE_INTEGRATION.md).

`references/ORIGINAL_PLAYBOOK.md` اصل پیوست است و تغییر نکرده؛ **قواعد ثابتِ ساعت/تست آن، قواعد رسمی ماز نیستند**. قالب بصری حفظ می‌شود؛ مدل پرکردن محتوا جایگزین می‌شود. طراحی کمکیِ بازیابی‌شده از مخزن قدیمی به تنهایی قالب تأییدشدهٔ Word نیست.

## ابزار کمکیِ قابل اجرا (نه موتور رسمی ماز)

```sh
python -m planner.schedule examples/student.json > examples/result.json
python -m planner.workload examples/workload.json
python -m unittest discover -s tests -v
```

کتابخانهٔ جانبی لازم نیست. این موتور، تسک‌های از قبل خردشده را در بازه‌های آزاد دانش‌آموز می‌چیند، تقدم و تأخر و فاصله‌های صریحِ تعیین‌شده در ورودی را رعایت می‌کند و باقی‌مانده را آشکار گزارش می‌دهد. استخراج بودجه، تشخیص پیش‌نیاز و تولید Word/PDF وظیفهٔ ایجنت طبق راهنماست؛ این‌ها در موتور پیاده‌سازی نشده‌اند. مثال مصنوعی است، نه برنامهٔ آزمون رسمی.

فایل‌های حجیم و متن کامل کتاب‌ها وارد Git نشده‌اند. اثرانگشت فایل‌های دریافت‌شده برای نسخهٔ اولیه در `references/inventory.json` و برای مجموعهٔ گسترش‌یافته در `research/page_audit.json` است. دانلود/استخراج متن به معنای تأیید تمام جدول‌های آن فایل نیست.
