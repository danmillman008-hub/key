# وضعیت واقعی پژوهش و کارهای باقی‌مانده

## انجام‌شده در این نسخه
- اصل پیوست در مخزن نگهداری شد؛ مخزن قبلی و طراحی قالب نیز از GitHub شناسایی شد.
- پوشهٔ «برنامه ریزی»، پوشهٔ مادر `ketab` و پوشهٔ کتاب‌های درسی ۱۴۰۵ در Drive فهرست شدند؛ نتیجهٔ این جست‌وجوی مشخص ۵۱ مورد بود، نه ادعای فهرست تمام درایو.
- ۱۴ PDF از منابع اصلی و مکمل دانلود شد؛ تعداد صفحه/اثر انگشت/طول متن در inventory ثبت است.
- نمونه‌های ماز دهم، یازدهم، دوازدهم، تابستان، مهر یک‌هفته‌ای، آبان و دی در دسترس قرار گرفت؛ راهنماهای کلیدی طبق محدودهٔ EVIDENCE بررسی شدند. هر جدول روزانهٔ همهٔ فایل‌ها هنوز سطر‌به‌سطر تأیید نشده است.
- PDF تصویرمحور ونوم، ۲۹ صفحه: رندر ۱٫۷ برابر با PyMuPDF و OCR فارسی با Tesseract.js و `tesseract-ocr/tessdata_fast/fas.traineddata` از GitHub انجام شد. تشخیص صفحه‌به‌صفحه ثبت شد؛ اطمینان موتور در محدودهٔ ۴۴ تا ۸۰ بود. این امتیاز احتمال صحت علمی نیست. متن ریز/ستونی و شمارهٔ تست‌ها بدون بازخوانی تصویری قابل استناد نیستند.
- دو صفحهٔ حساس ۱۲ و۱۳ نمونهٔ آبان دوازدهم با تصویر کنترل شد؛ متن پنهان/قدیمی و ناسازگاری حسابی مشخص شد.
- فرمول‌های عملی برای ظرفیت، حجم کار، تعداد تست، تقدم، انرژی، عقب‌ماندگی و بازخورد نوشته شدند؛ انتساب رسمی از پیشنهاد جدا شد.
- موتور کمکیِ زمان‌بندی و ۱۵ آزمون خودکار ساخته شد. این موتور استخراج بودجه، هوش مشاوره‌ای یا رندر قالب نیست.

## مرزهایی که هنوز باید تکمیل شوند
۱. تمام نمونه‌جدول‌های دهم/یازدهم/دوازدهم را با مختصات سلول و تاریخ، تعداد مطالعه/تست/مرور/انعطاف بازخوانی و مقایسهٔ آماری کنیم. استخراج متن بدون این کنترل، کشف نسبت‌های دقیق نیست.
۲. کتاب‌های درسی جدید فقط فهرست شده‌اند؛ همهٔ صفحاتشان در این نسخه خوانده/تطبیق نشده. برای الگوریتم زمان‌بندیِ مستقل از آزمون، ادعای تطبیق صفحه لازم نبود؛ برای اولین برنامهٔ واقعی، بودجه و صفحه‌های همان آزمون باید از کتاب صحیح کنترل شوند.
۳. اینترنت/سایت رسمی ماز در این اجرا بررسی نشد؛ محیط فقط چند میزبان مجاز دارد. تاریخ‌های فایل‌های قدیمی نباید به سال جاری منتقل شوند.
۴. شاهد مستقیم برای تمام تیپ‌های زندگی به‌ویژه پشت‌کنکور شاغل/خواب/سلامت نداریم؛ سیاست‌های آن‌ها در SCENARIOS پیشنهادند، نه فرمول اثبات‌شدهٔ رسمی ماز.
۵. این بسته فایل‌های راهنما و نمونهٔ JSON تولید کرده است؛ تحویل DOCX/PDF دانش‌آموز یا اثبات برابری بصری با Stitch14 انجام نشده.
۶. برای اعتبارسنجی عملی، چند شرح واقعیِ ناشناس از دانش‌آموز دهم/یازدهم/دوازدهم/فارغ‌التحصیل و گزارش اجرای یک دوره لازم است. نتیجهٔ موفق تست نرم‌افزار معادل اثربخشی آموزشی نیست.

## بازتولید خواندن منابع
فایل‌های خام در `google_drive/` و متن/OCR در `.work/` هستند و به دلیل حجم و حقوق منابع وارد Git نمی‌شوند. متن با نرمال‌سازی Unicode NFKC و جداکنندهٔ شمارهٔ صفحه استخراج شد. NFKC خطاهای فونت و ترتیب جدول را حل نمی‌کند. برای OCR فارسی می‌توان Tesseract.js محلی و مدل فارسی GitHub را روی PNG هر صفحه اجرا کرد؛ سپس اعداد/واژه‌های تعیین‌کننده را با تصویر اصلی تطبیق داد. نسخه و هش وابستگی‌های به‌کاررفته در `references/ocr_run.json` ثبت شده است. خروجی OCR برای مصرف داخلی است، نه محصول درخواستی کاربر.
