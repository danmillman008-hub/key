# وضعیت واقعی پژوهش — نسخهٔ۰٫۲، ۱۸اکتبر۲۰۲۶

## تکمیل‌شده در بازبینی جدید
- فایل‌های تقسیم‌شدهٔ حجیم دریافت شدند؛ **مانع۱۰۰MiB قبلی برطرف شده** و درخواست تقسیم دوباره لازم نیست.
- مجموعهٔ محلی اکنون۳۴PDF اصلی/تقسیم‌شده و یکPDF داخلیِ ساخته‌شده از۲۰تصویر آرشیو دارد: **۳۵سند،۱۰۱۵صفحه**. تصاویر ZIP قبلاً با جست‌وجوی صرفِ PDF دیده نمی‌شدند؛ اکنون وارد ممیزی شده‌اند. این آمار، فهرست تمام Drive نیست.
- برای **تمام۱۰۱۵صفحه** متن بومی، واژه و مختصات، تصویرهای توکار، بردار/رنگ/مستطیل‌ها، لینک/حاشیه‌نویسی و تصویر بندانگشتی استخراج شد. هش و وضعیت هر صفحه در `research/page_audit.json` است.
- **۵۱۱صفحهٔ نامزد OCR** پردازش شدند، بدون خطای اجرای ثبت‌شده. این مجموعه شامل اسکن‌ها، تصویرهای آرشیو و صفحات دارای صرفاً واترمارک است. امتیاز اطمینان OCR احتمال صحت مطلب نیست. «اجرای موفق» به معنای متن بی‌غلط یا خواندن معنایی کامل نیست.
- **۳۶جدول و۴۱۵۴خانهٔ نامزد** از هندسهٔ PDF استخراج شدند؛ مختصات، رنگ، تاریخ/زنگ و متن در `data/maz_tables.json` ثبت است. این‌ها رونویسیِ تأییدشده یا آمار رسمی ماز نیستند. شکل‌های پنهان/تکراری و خانه‌های ادغام‌شده هنوز نیازمند کنترل‌اند.
- بازبینی تصویریِ منتخب، از جمله جدول پُرشدهٔ دوازدهم آبان و راهنمای دو کتاب، انجام شد؛ دامنهٔ دقیقِ پاس جدید در `research/visual_review.json`، پاس‌های قبلی در `EVIDENCE.md` و یافته‌های تحلیلی در `REVERSE_ENGINEERING.md` است. نمای کلیِ۲۰صفحهٔ اول دو کتاب هم دیده شد؛ با بازخوانی تمام ریزنوشته‌ها برابر نیست.
- وب رسمی ماز واقعاً خوانده شد؛ ادعای قبلی «اینترنت بررسی نشد» دیگر درست نیست. مقالهٔ رسمی، نسبت۲به۳، مرور۲–۳روز بعد، ظرفیت شخصی و جبران هفتگی را بیان می‌کند؛ تفسیر و تعارض‌ها ثبت شده‌اند.
- فرمول اولیه حسابرسی شد: آموزش۹ساعت و تمرین/تحلیل۳۸ساعت از۴۷ساعت؛۴۹۵تست هفتگی و۵۴باکس دوهفته‌ای از همان فرض‌ها به دست می‌آیند. این پروفایل حفظ شده ولی همگانی فرض نمی‌شود.
- فرمول اجراییِ پارامتریک، محاسبهٔ بار و کسری، قرارداد پرکردن باکس و اتصال به renderer اصلی نوشته شدند. **۲۵آزمون خودکار** می‌گذرند؛ شامل کنترل حسابِ فرمول قبلی و رگرسیون هندسهٔ جدول. این موفقیت اثربخشی آموزشی را اثبات نمی‌کند.

## کارهایی که هنوز تمام نشده‌اند
۱. **تمام صفحات/تمام خانه‌ها از نظر معنایی و تصویری تأیید نشده‌اند.** پوشش استخراج۱۰۰٪ مجموعهٔ محلی است، نه پوشش بازخوانی انسانی۱۰۰٪. برای ادعای «هیچ نکته‌ای جا نیفتاده»، باید جدول‌ها و مقاله‌های باقی‌مانده با تصویر بازخوانی و به دفتر شواهد افزوده شوند.
۲. برخی متن‌های بومی فونت خراب یا متن پنهان قدیمی دارند؛ OCR کم‌متن فقط یکی از مسیرهاست. راهنمای رنگ و متن ظریف/دستخط نیازمند بازخوانی است. شمارش دسته‌های ماشینی نباید نسبتِ رسمی قلمداد شود.
۳. همهٔ کتاب‌های درسی جدید هنوز صفحه‌به‌صفحه با بودجه‌ها تطبیق نشده‌اند. برای برنامهٔ واقعی، صفحه/چاپِ همان درس و همان آزمون باید جدا کنترل شود. نام فایل یا حافظه جای شاهد نیست.
۴. عنوان دقیق فایل `(7)` احراز نشده؛ واترمارک کتابیکو عنوان کتاب نیست. تمام مقاله‌های۲۷۰صفحهٔ «همراه من» و۱۴۰صفحهٔ فایل۷ هنوز در دفتر شواهد تحلیل نشده‌اند، هرچند استخراج/OCR مربوط انجام شده است.
۵. renderer اصلی و قرارداد داده از مخزن قبلی شناسایی شدند؛ تغییر JSON به تنهایی کافی نیست چون چند تیتر/تاریخ/پانوشت قدیمی در کد ثابت‌اند. `TEMPLATE_INTEGRATION.md` محل و اصلاح لازم را مشخص می‌کند. **DOCX/PDF جدیدِ دانش‌آموز و تأیید برابری بصری آن هنوز تولید نشده**.
۶. سیاست حالت‌های شغل/سلامت/عقب‌ماندگی، صورت‌بندی پیشنهادی و قابل محاسبه است؛ نسبت‌دادن ضرایب ابداعی به الگوریتم داخلی ماز مجاز نیست. اعتبارسنجی با گزارش اجرای واقعی دانش‌آموزان هنوز لازم است.

بنابراین این نسخه یک **بستهٔ اجراییِ بهبود‌یافته با مرز شواهد صریح** است، نه ادعای پایان بازخوانی همهٔ منابع یا کشف الگوریتم محرمانهٔ مؤسسه.

## بازتولید استخراج داخلی
فایل خام در `google_drive/` و خروجی ریز در `.work/full/` است؛ به دلیل حجم و حقوق منابع وارد Git نمی‌شوند. خروجی OCR محصول تحویلیِ مورد درخواست نیست.

```sh
python -m venv .venv
.venv/bin/pip install -r scripts/requirements.txt
.venv/bin/python scripts/audit_pdfs.py
.venv/bin/python scripts/extract_tables.py
npm install --prefix scripts
# مدل fas.traineddata از tesseract-ocr/tessdata_fast در GitHub تهیه و در
# .work/ocr/lang قرار داده شود (gzip:false). کد مسیر را از همین محل می‌خواند.
node scripts/ocr_pages.cjs
python scripts/summarize_coverage.py
python -m unittest discover -s tests -v
```

در محیط این اجرا Tesseract.js در `.work/ocr/node_modules` نصب بود و با `NODE_PATH="$PWD/.work/ocr/node_modules"` اجرا شد. نسخهٔ آزمودهٔ PyMuPDF۱٫۲۸٫۲ و Tesseract.js۷٫۰٫۰ است. ابزار ممیزی باید از ریشهٔ مخزن اجرا شود. `visual_review:false` در ممیزی خودکار تعمدی است؛ فقط manifest بازبینی منتخب دامنهٔ دیدن تصاویر را مشخص می‌کند.
